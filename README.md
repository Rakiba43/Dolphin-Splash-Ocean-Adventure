# 🐬 Dolphin Splash – Ocean Adventure

A colorful 2D animated mini-game developed using Python and PyOpenGL for my Computer Graphics Lab project.

## 🎮 About the Project

Dolphin Splash is a small ocean adventure game where the player controls a dolphin, jumps over obstacles, and collects pearls while exploring an animated ocean environment.

## ✨ Features

- Dolphin jumping animation
- Animated ocean waves
- Pearl collection and scoring system
- Rock obstacles and collision detection
- Underwater fish and bubbles
- Pause and restart functionality

## 🛠️ Technologies Used

- Python
- PyOpenGL
- GLUT
- OpenGL

## 🎮 Controls

| Key | Action |
|---|---|
| SPACE | Jump |
| P | Pause / Resume |
| R | Restart |
| ESC | Exit |

## 🚀 How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the game:

```bash
python dolphin_splash.py
```
